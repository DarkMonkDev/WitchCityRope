## File Maintenance Guidelines

### Status Definitions
- **ACTIVE**: Permanent file, part of active codebase
- **TEMPORARY**: Created for specific session, should be cleaned up
- **ARCHIVED**: Moved to archive, kept for reference
- **DELETED**: Removed from codebase

### Cleanup Process
1. Review "Cleanup Date" column weekly
2. For TEMPORARY files past cleanup date:
   - Verify file is no longer needed
   - Move to archive or delete
   - Update registry status
3. For ACTIVE files:
   - Ensure documentation is up-to-date
   - Verify file serves intended purpose

### Best Practices
- ALWAYS log file operations in this registry
- Use descriptive purposes
- Set realistic cleanup dates
- Review registry before session end
- Clean up temporary files promptly
