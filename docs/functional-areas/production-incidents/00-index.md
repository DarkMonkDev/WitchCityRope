## Severity Definitions

- **CRITICAL** — active data loss, site down, security breach, payments failing
- **HIGH** — degraded functionality or intermittent user-impacting errors
- **MEDIUM** — potential problems, non-critical warnings, performance concerns
- **LOW** — cosmetic issues, optimization opportunities
- **OK** — clean baseline report, no action items

## Severity of an Incident

Severity equals the highest priority issue found in the report. An incident with one HIGH + three MEDIUMs is logged as HIGH.

## Status Values

- **Open** — issues still live / not addressed
- **Partially resolved** — some but not all items fixed; keep tracking
- **Resolved** — all items fixed; kept for historical record
- **Superseded** — a later report replaced this one as the current picture
